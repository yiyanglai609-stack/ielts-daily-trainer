今日做题提醒
1. 提到了 ≠ 答案。
2. 听到和选项一模一样的词，不要马上选，先听完整关系。
3. 上一题最多丢1分，继续想上一题可能再丢下一题。
4. Part 4 听到 first / another factor / however / in contrast / finally 等结构词，要准备往下一题移动。
5. 填空题预读先判断词性：名词、动词、形容词、数字、地点还是类别。
6. 听到了但来不及打完整，可以先写词干前几个字母，避免过几秒完全忘掉。
7. 错题复盘标记：H=没听到，V=词不认识，T=干扰项，A=注意力掉线，S=拼写/单复数。

后续每天把阅读错题发来后，会继续加入：Heading、T/F/NG、Matching Names、定位词、同义替换、长难句。
Heading提醒： 选整段主旨，不选只出现过一次的细节。
人名题提醒： 人名是定位词；Heading里人名通常只是例子。
优先看： 首句、尾句、however / but / although / instead 等转折位置。
口语训练区
回答顺序：Answer → Why → Example / Detail
不需要强行用高级词，卡住时优先换简单表达，保证流利度。
常用救场：
I haven't really thought about this before, but I'd say...
The main reason is probably that...
A good example would be...
写作训练区
每段只保留一个清晰中心观点。
检查：主谓一致、冠词、单复数、时态。
不临时换新模板，优先保证逻辑完整和表达准确。
